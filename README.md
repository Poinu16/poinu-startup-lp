# カロリーメイト LP 練習

## サービス概要

- **リポジトリ**: `Poinu16/poinu-startup-lp`
- **種別**: ランディングページ（LP）
- **一言で**: 忙しい朝の学生・若者に向けて、カロリーメイトの手軽な栄養補給を伝えるLP

## 目的（1ページ1ゴール）

商品購入につなげる

- 継続購入したくなるきっかけも作る

## 想定ターゲット

- **ペルソナ**: 20代までの学生、朝の通学や通勤で時間がない若者、部活や運動をしている学生
- **課題（インサイト）**: 朝は忙しく食事をしっかり取れない、手軽に栄養補給したい、通学・通勤前や運動前後にすぐ食べられるものがほしい

## KGI / KPI（任意）

- **KGI**: 商品購入
- **KPI**: 購入ボタンのクリック、商品詳細の閲覧
